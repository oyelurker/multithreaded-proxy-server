Where the time went

Of 155 ms, only about 25 ms was the server and database actually working. The other ~130 ms was messages crossing the network.

✓ DNS turns names into addresses; answers are cached.
✓ Connections cost round trips — reuse them.
✓ Server code is often the smallest slice of latency — unless a slow query sneaks in.
✓ Distance multiplies every round trip.
